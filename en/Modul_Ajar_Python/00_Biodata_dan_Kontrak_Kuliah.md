## Course Description & Objectives
The **Algorithms and Programming** course covers the basic concepts of algorithms, programming logic, and computational problem-solving techniques by constructing algorithms and implementing them using a programming language. 

The course material includes algorithm concepts, *pseudocode*, *flowcharts*, data types, variables, operators, control structures, functions/procedures, *arrays*, *strings*, *debugging* techniques, program testing, and simple application development. 

**Learning Objectives:**
After completing this course, students are expected to be able to analyze computational problems, design effective algorithms, implement solutions as programs, perform testing and *debugging*, and document the developed program according to good programming principles.

## Course Learning Outcomes (CPMK)
By the end of the learning process, students are expected to be able to:
1. **Explain** the basic concepts of computing, algorithms, programming logic, data types, operators, and control structures as the foundation for computer programming.
2. **Apply** mathematical concepts and computational logic to construct algorithms, *flowcharts*, *pseudocode*, and implement simple programs.
3. **Analyze** computational problems and construct effective and efficient solving algorithms using a structured programming approach.
4. **Design** simple software solutions by implementing functions/procedures, *arrays*, *strings*, as well as testing and *debugging* techniques.
5. **Implement, test, and evaluate** simple programs according to user needs by applying good, well-documented programming principles.

## Course Contract
Rules and agreements for the Algorithms and Programming course:

1. **Attendance:** Minimum face-to-face attendance percentage according to academic rules (e.g., 75%).
   - Absence due to SICKNESS/LEAVE/Organizational Duty -> Must attach valid documentation/proof.

   - Assignments & Quizzes: 20%
